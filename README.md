# 数学查漏补缺工作台 · gap_tool

本地学习辅助工具。把「视频（mp4）+ 字幕（srt）+ AI 笔记（html）」三者按同名 /
文件名包含关系自动关联，提供课程树、笔记搜索高亮、字幕随播放高亮、双击字幕跳播等能力。

**纯前端运行，无需任何服务器**：所有文件读取与解析都在浏览器本地完成，数据不上传。

## 功能

- **选文件夹即用**：点「选择课程文件夹」选中含 mp4 / srt / html 的目录，浏览器本地扫描关联
  （字幕与同名 mp4 自动匹配，笔记按文件名关联）
- **课程树**：按目录结构生成，可折叠 / 隐藏 / 拖宽
- **AI 笔记区**：加载对应 html，支持关键字搜索高亮（忽略空白差异，如 `4 + 15` 可命中 `4+15`）
- **字幕区**：解析 srt，搜索高亮、播放跟随高亮（当前句自动高亮并滚入视区）、双击跳播
- **视频区**：可隐藏 / 拖宽，双击字幕行跳到对应时间点

## 使用（在线 / 静态托管）

1. 用 **Chrome 或 Edge** 打开网站（如 https://xbee129.github.io/manman-gap-tool/）
2. 点「选择课程文件夹」，选中你本机最外层课程文件夹（mp4 / srt / html 同处其中）
3. 左侧课程树点 mp4 叶子 → 右侧加载视频、中间加载笔记与字幕
4. 搜索框输入关键字 → 笔记区与字幕区同步高亮
5. 播放视频 → 字幕区当前句自动高亮；双击字幕行跳播

> 说明：选文件夹依赖浏览器 `webkitdirectory` 能力，仅 Chromium 系（Chrome / Edge）支持；
> Firefox / Safari 不支持，请用 Chrome / Edge 打开。

## 使用（本地直接打开）

直接双击 `index.html` 用 Chrome / Edge 打开亦可，同样点「选择课程文件夹」即可，无需启动服务。

## 关联规则

- **字幕**：与 mp4 同名（归一化后）的 srt
- **笔记**：文件名（归一化后）包含 mp4 文件名的 html，优先精确同名

## 目录

```
gap_tool/
├── index.html     # 前端（纯浏览器版）：课程树 + AI 笔记区 + 字幕区 + 视频区，无后端依赖
├── server.py      # 仅本地可选：旧版 Python 后端（扫描目录/解析 srt/serve 视频），现已非必需
├── start.bat      # Windows 一键启动（启动 server.py）
└── .gitignore     # 排除运行时产物 index.json / 日志 / __pycache__
```
