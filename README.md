# 数学查漏补缺工作台 · gap_tool

本地学习辅助工具。把「视频（mp4）+ 字幕（srt）+ AI 笔记（html）」三者按同名 /
文件名包含关系自动关联，提供课程树、笔记搜索高亮、字幕随播放高亮、双击字幕跳播等能力。

## 功能

- **单路径加载**：把 mp4 / srt / html 放在同一文件夹，填一个路径即可加载
  （字幕亦自动匹配同级 ASR 目录）
- **课程树**：按目录结构生成，可折叠 / 隐藏 / 拖宽
- **AI 笔记区**：加载对应 html，支持关键字搜索高亮（忽略空白差异，如 `4 + 15` 可命中 `4+15`）
- **字幕区**：解析 srt，搜索高亮、播放跟随高亮（当前句自动高亮并滚入视区）、双击跳播
- **视频区**：可隐藏 / 拖宽，双击字幕行跳到对应时间点

## 运行

需要 Python 3.8+（仅标准库，无第三方依赖）。

```bash
cd gap_tool
python server.py          # 默认端口 8770，可用环境变量 PORT 覆盖
```

Windows 用户双击 `start.bat` 可直接启动并打开浏览器。

## 使用

1. 浏览器打开 http://127.0.0.1:8770/
2. 配置栏填入课程文件夹路径（含 mp4 / srt / html），点「加载」
3. 左侧课程树点 mp4 叶子 → 右侧加载视频、中间加载笔记与字幕
4. 搜索框输入关键字 → 笔记区与字幕区同步高亮
5. 播放视频 → 字幕区当前句自动高亮；双击字幕行跳播

## 关联规则

- **字幕**：与 mp4 同名（归一化后）的 srt
- **笔记**：文件名（归一化后）包含 mp4 文件名的 html，优先精确同名

加载时生成 `index.json`（含目录树与对应关系），可随课程文件夹移动。

## 目录

```
gap_tool/
├── server.py      # 本地服务：扫描课程目录 → 生成 JSON 树、解析 srt、serve 视频/笔记
├── index.html     # 前端：课程树 + AI 笔记区 + 字幕区 + 视频区
├── start.bat      # Windows 一键启动
└── .gitignore     # 排除运行时产物 index.json / 日志 / __pycache__
```
